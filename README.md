# 电网生产ERP管理系统（本地自托管版）

> 一套可完全离线运行、数据全部保留在本机的电网生产业务管理系统。
> 覆盖从项目立项、计划排期、借工调度，到竣工资料、文档中心与材料台账的核心生产管理流程。

---

## 一、产品简介

本系统是一个 **本地自托管** 的电网生产 ERP：

- 无需联网、无需云端账号，所有数据保存在本机文件中；
- 覆盖工程项目全生命周期的生产管理场景；
- 采用零构建架构，开箱即用，便于二次开发与内网部署。

**首次启动即为纯净空实例**：不含任何演示数据。企业名称、年度计划、属地供电所、班组、人员、项目、材料等均需在登录后自行录入。

**默认管理员账号**：`admin / admin123`（角色：超级用户）。首次登录后请尽快修改密码，并在「全局设置」中填写企业名称等基础信息。

---

## 二、技术栈

- **后端**：Node.js + Express，本地 JSON 文件存储（`data/db.json`，零外部数据库依赖，最大可移植）
- **前端**：Vue 3 + Element Plus
  - 采用**离线运行时全局构建**（`public/vendor/` 内置 `vue.global.prod.js`、`element-plus.full.min.js`、`element-plus.css`）
  - 运行时模板编译，**无需 webpack/vite 等打包工具**，浏览器直接打开即可
- **鉴权**：轻量级 Bearer Token（登录后存 `localStorage`）
- **部署**：支持原生 `node` 启动，也支持 Docker 一键部署

## 三、快速开始

### 1. 安装依赖

```bash
npm install      # 仅依赖 express / multer / xlsx
```

### 2. 启动

```bash
npm start
# 或自定义端口： PORT=8080 npm start
```

启动后控制台输出：

```
电网生产ERP（本地版）已启动
➜  本地访问: http://localhost:5173
➜  默认账号: admin / admin123  (角色: 超级用户)
```

### 3. 打开使用

浏览器访问 **http://localhost:5173** ，用默认账号登录即可。

> 手机端已做 iPhone 系列自适应适配，可在同一局域网内用手机浏览器直接访问（请使用本机局域网 IP 或 `.local` 域名，而非 `localhost`）。

## 四、功能模块一览

| 菜单 | 模块 | 说明 |
|------|------|------|
| 首页 | 工作台 | 项目 / 物料 / 领料单 / 文档 / 借工 数量概览 |
| 项目列表 | 项目管理 | 年度计划 + 属地供电所（项目必填依赖）、电压等级、类型、经理、状态、进度、起止日期 |
| 计划管理 | 计划 | 分阶段计划、负责人、起止、状态、进度 |
| 借工管理 | 借工 | 借出 / 借入班组、事由、人数、状态 |
| 竣工资料 | 竣工资料 | 资料名称、类别、状态（编制中 / 待审核 / 已归档） |
| 文档中心 | 文档中心 | 多分类（规范文件 / 工作票模板 / 检查表 / 奥维地图 / 未分类）+ 企业危险点库（支持新增 / 编辑 / 删除 / 排序 / Excel 导入去重）+ 固定模板文件（危险点.xlsx、现场勘察记录模板.docx 可预览 / 替换）；用户上传文件存 `data/uploads/`，支持上传 / 下载 / 预览（docx / xlsx）/ 移动分类 / 删除 |
| 材料台账 | 材料台账 | 4 个子页签：材料明细 / 领料单 / 导入批次 / 出库管理；搜索 / 筛选 / 分页；新增编辑删除；**支持 Excel 导入**（按采购申请模板列解析批量建物料，到库状态随数量自动计算）；可一键下载导入模板 |
| 全局设置 | 设置 | 5 标签页：① 年度计划名称 ② 属地供电所 ③ 班组管理 ④ 材料目录 ⑤ 网站设置（企业名称、欢迎语、Logo 等） |

## 六、数据存储与重置

- 所有数据保存在 **`data/db.json`**（项目、计划、借工、竣工资料、材料、领料单、导入批次、出库、作业人员、外部通讯录、年度计划、属地供电所、材料目录、班组、文档、用户、设置、登录令牌）。
- 数据**完全保存在本机，不上传任何云端**。
- **重置为初始空实例**：停止服务后删除 `data/db.json`，再次启动即自动重新初始化（所有业务数据清空，企业名称等需重新设置）。

## 七、部署

### 原生启动

```bash
npm install && npm start
```

### Docker

```bash
docker compose up -d --build
# 访问 http://localhost:5173
```

数据持久化：`./data` 挂载为卷；容器内 `data` 为空时首次启动自动初始化为空实例。

## 八、已知限制 / 可扩展方向

1. **鉴权为轻量级**：Token 存于内存并持久化到 `db.json`，适合本地 / 内网使用；如需生产级安全可替换为 JWT + 密码哈希。
2. **多团队隔离**：当前通过「团队管理」实现母账号 + 团队子空间的逻辑隔离；如需跨组织强多租户可进一步扩展。
3. **材料台账「导入批次」** 目前作批次记录登记；「材料明细」已支持真实 Excel 导入。
4. 可将 JSON 存储平滑切换为 SQLite（`better-sqlite3`）以获得更高并发与查询能力。
